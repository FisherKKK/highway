**技术要点：**

**性能目标：**

- 比 OpenCV 快 1.5-3x

**参考代码：**
```cpp
// 高斯模糊伪代码
template <class D>
void GaussianBlur3x3(D d, const uint8_t* in, uint8_t* out,
                     int width, int height) {
  const RebindToFloat<D> df;
  // 可分离：先水平，后垂直
  for (int y = 0; y < height; ++y) {
    // 水平卷积（向量化）
    for (int x = 0; x < width; x += Lanes(d)) {
      auto left = LoadU(d, &in[y*width + x-1]);
      auto center = LoadU(d, &in[y*width + x]);
      auto right = LoadU(d, &in[y*width + x+1]);

      auto sum = MulAdd(ConvertTo(df, center), Set(df, 0.5f),
                        Mul(Add(ConvertTo(df, left), ConvertTo(df, right)),
                            Set(df, 0.25f)));
      StoreU(DemoteTo(d, sum), d, &temp[y*width + x]);
    }
  }
  // 垂直卷积类似...
}
```

**扩展方向：**
- 支持浮点图像（HDR）
- GPU 加速版本（CUDA/OpenCL）
- 实时摄像头处理

- > 1 GB/s 解析速度

**核心代码：**
```cpp
// 快速查找分隔符
template <class D>
size_t FindNextDelimiter(D d, const char* data, size_t pos, size_t end) {
  auto comma = Set(d, ',');
  auto newline = Set(d, '\n');

  for (size_t i = pos; i < end; i += Lanes(d)) {
    auto chars = LoadU(d, reinterpret_cast<const uint8_t*>(&data[i]));
    auto is_delim = Or(Eq(chars, comma), Eq(chars, newline));

    if (AnyTrue(d, is_delim)) {
      return i + FindFirstTrue(d, is_delim);
    }
  }
  return end;
}
```

### 项目 10: K-Means 聚类

**难度：** 🌟 入门 | **时间：** ⏱️ 周末

**描述：**
向量化的 K-Means 聚类算法。

**技术要点：**
- 距离计算向量化（欧氏距离）
- 质心更新优化
- 并行处理样本

**核心循环：**
```cpp
// 计算点到质心的距离
template <class D>
void ComputeDistances(D d, const float* point, const float* centroids,
                      float* distances, int k, int dims) {
  for (int i = 0; i < k; ++i) {
    auto sum = Zero(d);
    for (int j = 0; j < dims; j += Lanes(d)) {
      auto p = LoadU(d, &point[j]);
      auto c = LoadU(d, &centroids[i*dims + j]);
      auto diff = Sub(p, c);
      sum = MulAdd(diff, diff, sum);  // sum += diff²
    }
    distances[i] = ReduceSum(d, sum);
  }
}
```
