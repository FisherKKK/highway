## 📖 每日学习计划

### 第 1 天：项目概览和基本概念
**学习时长**: 2-3 小时
**核心文件**: `README.md`, `hwy/highway.h`, `examples/skeleton.cc`
**关键概念**:
- SIMD 是什么，为什么需要 Highway
- 项目目录结构
- 静态分发 vs 动态分发
- 第一个 Highway 程序

**练习**:
1. 编译并运行 `examples/skeleton.cc`
2. 修改示例，实现简单的向量加法
3. 尝试在不同编译选项下观察生成的汇编代码

**练习**:

## 🔑 核心概念速查

### 类型系统

| 概念 | 说明 | 示例 |
|------|------|------|
| `ScalableTag<T>` | 全向量宽度，适应硬件 | `ScalableTag<float> df;` |
| `CappedTag<T, N>` | 最多 N 个通道 | `CappedTag<uint8_t, 16> d;` |
| `FixedTag<T, N>` | 恰好 N 个通道 | `FixedTag<int32_t, 4> d;` |
| `Vec<D>` | 向量类型 | `auto v = Zero(d);` |
| `Mask<D>` | 掩码类型 | `auto m = Lt(v1, v2);` |
| `Rebind<NewT, D>` | 改变通道类型，保持通道数 | `Rebind<float, decltype(d)>` |
| `Repartition<NewT, D>` | 改变通道类型，保持总字节数 | `Repartition<uint16_t, decltype(d)>` |

### 常用操作

| 类别 | 操作 | 说明 |
|------|------|------|
| **加载/存储** | `Load, LoadU` | 对齐/非对齐加载 |
| | `Store, StoreU` | 对齐/非对齐存储 |
| | `MaskedLoad, BlendedStore` | 条件加载/存储 |
| **算术** | `Add, Sub, Mul, Div` | 基本算术 |
| | `MulAdd, NegMulAdd` | 融合乘加 (FMA) |
| | `SaturatedAdd, SaturatedSub` | 饱和运算 |
| **逻辑** | `And, Or, Xor, Not` | 位运算 |
| | `ShiftLeft, ShiftRight` | 位移 |
| **比较** | `Eq, Ne, Lt, Le, Gt, Ge` | 返回掩码 |
| **排列** | `Shuffle*, TableLookup*` | 通道重排 |
| | `InterleaveLower, InterleaveUpper` | 交错 |
| | `Broadcast` | 广播单个通道 |
| **归约** | `SumOfLanes, MinOfLanes, MaxOfLanes` | 水平归约 |
| **转换** | `PromoteTo, DemoteTo` | 类型提升/降级 |
| | `ConvertTo` | 类型转换 |
| | `BitCast` | 位重解释 |

### 分发机制

| 类型 | 宏 | 使用场景 |
|------|------|----------|
| **静态分发** | `HWY_STATIC_DISPATCH` | 单一目标，零开销 |
| **动态分发** | `HWY_DYNAMIC_DISPATCH` | 多目标，运行时选择 |
| **导出** | `HWY_EXPORT` | 创建函数指针表 |
| **命名空间** | `HWY_NAMESPACE` | 目标特定代码 |

### 测试模式

```cpp
// 测试所有类型和大小
ForAllTypes(ForPartialVectors<TestStruct>());

// 仅测试整数类型
ForIntegerTypes(ForPartialVectors<TestStruct>());

// 仅测试浮点类型
ForFloatTypes(ForPartialVectors<TestStruct>());

// 仅测试有符号类型
ForSignedTypes(ForPartialVectors<TestStruct>());
```

## 💡 学习技巧

### 1. 源码阅读策略

**自顶向下**:
```
1. 从示例代码开始 (examples/skeleton.cc)
2. 追踪 highway.h 的包含链
3. 查看 ops/*-inl.h 的具体实现
4. 深入到 intrinsics 细节
```

**自底向上**:
```
1. 先理解 base.h 的基础工具
2. 学习 scalar-inl.h 的简单实现
3. 对比 x86_128-inl.h 的真实 SIMD 实现
4. 理解 foreach_target.h 的分发魔法
```

### 2. 调试技巧

**打印向量值**:
```cpp
const ScalableTag<float> d;
auto v = Load(d, data);

// 方法1: 存储后打印
float buf[MaxLanes(d)];
Store(v, d, buf);
for (size_t i = 0; i < Lanes(d); ++i) {
  printf("v[%zu] = %f\n", i, buf[i]);
}

// 方法2: 使用 GetLane (仅限 Scalar/小向量)
printf("v[0] = %f\n", GetLane(v));
```

**查看汇编代码**:
```bash
# GCC
g++ -S -O3 -march=native -masm=intel your_code.cc

# Clang
clang++ -S -O3 -march=native -masm=intel your_code.cc

# 仅查看特定函数
objdump -d your_binary | grep -A 50 YourFunction
```

**使用 Compiler Explorer**:
- 访问 https://godbolt.org/
- 选择 x64 gcc/clang
- 添加 `-march=native -O3` 编译选项
- 实时查看汇编输出

### 3. 性能分析

**Benchmarking 模板**:
```cpp
#include <chrono>

template <typename Func>
double BenchmarkMs(Func&& func, size_t iterations = 1000) {
  auto start = std::chrono::high_resolution_clock::now();
  for (size_t i = 0; i < iterations; ++i) {
    func();
  }
  auto end = std::chrono::high_resolution_clock::now();
  auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
  return duration.count() / 1000.0;
}

// 使用
double time = BenchmarkMs([&]() {
  MyVectorizedFunction(data, size);
});
printf("Time: %.2f ms\n", time);
```

**使用 perf (Linux)**:
```bash
# 计数器分析
perf stat -e cycles,instructions,L1-dcache-load-misses ./your_program

# 热点分析
perf record -g ./your_program
perf report
```

### 4. 常见陷阱

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 段错误 (SIGILL) | 运行不支持的指令 | 确保动态分发正确，或使用静态分发的正确目标 |
| 性能不如预期 | 非对齐访问 | 使用 `AlignedAlloc` 或 `LoadU`/`StoreU` |
| 编译错误 | 忘记 `HWY_NAMESPACE` | 确保在正确的命名空间内调用操作 |
| 测试失败 | 浮点精度问题 | 使用 `AssertArraySimilar` 而非 `AssertArrayEqual` |
