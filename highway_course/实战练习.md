## 🏆 综合项目：图像高斯模糊

**时间**: 3-4 小时
**难度**: ⭐⭐⭐

### 项目描述

实现一个完整的图像高斯模糊算法，应用所学的所有知识。

### 要求

1. **输入**: RGB 图像（宽×高×3）
2. **输出**: 模糊后的图像
3. **核大小**: 5×5
4. **优化**: 使用向量化、分离卷积、并行化

### 步骤

**Step 1: 实现基础卷积**
```cpp
void Convolve(const uint8_t* input, size_t width, size_t height,
              const float* kernel, size_t kernel_size,
              uint8_t* output);
```

**Step 2: 优化为分离卷积**
```cpp
// 水平方向
void ConvolveHorizontal(const uint8_t* input, size_t width, size_t height,
                        const float* kernel, size_t kernel_size,
                        float* temp);

// 垂直方向
void ConvolveVertical(const float* temp, size_t width, size_t height,
                      const float* kernel, size_t kernel_size,
                      uint8_t* output);
```

**Step 3: 向量化卷积核**
- 使用 Highway 的 `MulAdd` 实现融合乘加
- 使用 `Load` 和 `LoadU` 处理边界
- 使用 `Transform` 简化循环

**Step 4: 性能测试**
- 对比标量版本和向量版本
- 测量不同图像大小的性能
- 使用 `perf` 分析缓存命中率

### 评分标准

- **正确性** (40分): 输出图像正确
- **性能** (30分): 相比标量版本的加速比
- **代码质量** (20分): 可读性、注释、错误处理
